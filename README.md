# ARVECTA Technologies

Sitio corporativo y sistema de marca de **ARVECTA TECHNOLOGIES, S.A.S.**

> **Construir. Integrar. Evolucionar.**

ARVECTA Technologies diseña, desarrolla e integra software, plataformas, datos, automatización y sistemas digitales para organizaciones privadas y públicas.

## Repositorio

Este repositorio concentra dos activos principales:

1. **Sitio corporativo** listo para ejecución local y despliegue estático.
2. **Brand system** con masters del logo, isotipo, versiones monocromáticas, colores, tipografía y manual de identidad.

## Ver localmente

```bash
git clone https://github.com/jiestrada/arvecta.git
cd arvecta
python3 -m http.server 8080
```

Después abre `http://localhost:8080`.
